# МИС — Медицинская информационная система

Комплексная информационная система для автоматизации работы медицинского учреждения. Включает регистрацию пациентов, электронную медицинскую карту, расписание приёмов, учёт коечного фонда и управление аптекой.

## 📋 Состав проекта

| Проект | Назначение | Технологии |
|--------|-----------|------------|
| **ClinicWebApp** | Веб-приложение: регистрация пациентов, госпитализация, карта больницы, коечный фонд | Blazor Server, .NET 8, MySQL |
| **ClinicApp** | Настольное приложение: расписание приёмов, фильтры, запись к врачу | Avalonia UI, .NET 8, MySQL |
| **PharmacyApi** | REST API для подсистемы «Аптека» | ASP.NET Core Web API, .NET 8, MySQL |
| **ClinicMobile** | Мобильное приложение для работы с аптекой | .NET MAUI |
| **Docs** | SQL-скрипты, UML-диаграммы, wireframes, руководство | — |

## 🛠️ Технологии

- **Язык:** C# 12
- **Платформа:** .NET 8
- **UI:** Blazor Server, Avalonia UI, .NET MAUI
- **БД:** MySQL 8.0
- **API:** ASP.NET Core Web API
- **ORM/доступ к данным:** MySql.Data (ADO.NET)
- **Библиотеки:** QRCoder, CommunityToolkit.Mvvm, DocumentFormat.OpenXml
- **Проектирование:** draw.io (UML, wireframes)

## 🚀 Функционал

### Сессия 1 — Управление потоком пациентов
- Регистрация пациентов (ФИО, паспорт, полис, контакты)
- Госпитализация (запись, отмена, сохранение в БД)
- Направления на лечебно-диагностические мероприятия
- Генерация QR-кодов медкарт

### Сессия 2 — Отслеживание и коечный фонд
- Карта отделения с движением людей (обновление каждые 3 сек)
- Персонал — синие кружки, клиенты — зелёные
- Коечный фонд отделения (палаты 101–118)
- Drag&Drop перевод пациента между койками
- Выписка через контекстное меню

### Сессия 3 — Электронная медицинская карта (проектирование)
- Диаграмма деятельности (UML Activity Diagram)
- Диаграмма последовательности (UML Sequence Diagram)
- 9 wireframes экранов ЭМК

### Сессия 4 — Администрирование и расписание
- Расписание приёмов врачей (дневное и недельное)
- Фильтры по дате, специальности, врачу
- Цветовые статусы (свободно / записан / отменён)
- Запись пациента к врачу
- Утверждение расписания главным врачом

### Сессия 5 — Аптека
- Список лекарственных препаратов и остатков на складах (через API)
- Поступление от поставщиков
- Списание с указанием причины
- Перемещение между складами
- Заявки отделений и фиксация отпуска
- Отчёт по необходимости заказа с подсветкой срочных позиций

## 🗄️ База данных

Все таблицы находятся в БД `clinic_db`. Скрипты:

- `Docs/DB/clinic_db_full.sql` — полный дамп БД
- `Docs/DB/session5.sql` — таблицы аптеки

### Основные таблицы

- `patients` — пациенты
- `hospitalizations` — госпитализации
- `medical_services` — лечебно-диагностические мероприятия
- `beds` — койки
- `doctors` — врачи
- `schedule` — расписание приёмов
- `schedule_history` — история изменений расписания
- `medicines` — лекарственные препараты
- `stocks` — остатки на складах
- `requests`, `request_items` — заявки отделений
- `stock_movements` — движения препаратов
